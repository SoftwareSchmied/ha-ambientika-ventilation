# Security policy

## Reporting a vulnerability

Do not open a public issue containing credentials, JWTs, email addresses,
complete serial numbers, private room/house names, precise locations, or raw API
payloads. Report suspected vulnerabilities through GitHub's private
**Security → Report a vulnerability** flow for this repository.

Include the smallest reproducible description possible and remove account,
device, network, and location identifiers. You should receive an acknowledgement
within seven days.

## Supported versions

Security fixes are provided for the latest published release. Users should
update through HACS before reporting an issue.

Revoke or change the Ambientika account password immediately if credentials or
a token were exposed.
